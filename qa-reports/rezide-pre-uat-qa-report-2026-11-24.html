The site loads and navigates cleanly: all 22 pages render on desktop and mobile with no errors, no horizontal scrolling and no broken images, and most journeys work end to end. Three things must be fixed before the client sees it: an account-data leak in the activity API (B1), a Next.js upgrade that the build now requires (B2), and Sale/Rental compare, which can’t load because its backend endpoint is missing (B3).

Before deploying UAT

  • Upgrade next and eslint-config-next to 16.4.6 before building UAT.
  • Serve UAT over HTTPS. The CSP includes upgrade-insecure-requests; over plain HTTP some page prefetches are upgraded to https and fail (seen locally as ERR_SSL_PROTOCOL_ERROR).
  • Set NEXT_PUBLIC_GOOGLE_MAPS_API_KEY at build time and allow the UAT domain in the key’s referrer restrictions; otherwise maps show a fallback.
  • Set LEAD_TRUST_PROXY=true when the app runs behind the UAT proxy/CDN (m3).
  • Confirm API_SERVER_BASE_URL / NEXT_PUBLIC_API_BASE_URL point at the backend the client should see, and that the backend has POST /Inventory/listing/ids (B3).
  • Check the Realtor Corner target for the UAT hostname (m4).
